# Complete Deployment Guide - Prático Digital

This guide walks through the complete setup process for deploying the Prático Digital application with Supabase backend and Resend email notifications.

## Overview

The application uses:
- **Frontend**: React + Tailwind CSS
- **Database**: Supabase (PostgreSQL) - Connected via Figma Make
- **Email**: Resend (via Supabase Edge Function)

## Architecture

When a user submits a form:
1. Frontend validates and submits data
2. Data is inserted into Supabase database
3. Supabase Edge Function is called
4. Edge Function sends email notification via Resend
5. Success state shown only if both steps succeed

## Prerequisites

- Node.js and pnpm installed
- Supabase connected via Figma Make settings (already done ✅)
- Resend account: https://resend.com

Follow the instructions in `SUPABASE_SETUP.md`:

1. Create Supabase project
2. Run SQL scripts to create tables:

3. Enable Row Level Security (RLS) policies

### 3. Email Setup (Resend)

1. Sign up at https://resend.com
2. For testing: Use `onboarding@resend.dev` (no verification needed)
3. For production: Add and verify your domain
4. Create an API key

### 4. Edge Function Deployment

Follow the instructions in `EDGE_FUNCTION_SETUP.md`:

1. Install Supabase CLI
2. Link your project
3. Set secrets:
   ```bash
   supabase secrets set RESEND_API_KEY=re_your_key
   supabase secrets set FROM_EMAIL=noreply@yourdomain.com
   supabase secrets set ADMIN_EMAIL=admin@yourdomain.com
   ```
4. Deploy the function:
   ```bash
   supabase functions deploy send-form-notification
   ```

### 5. Install Dependencies

```bash
pnpm install
```

### 6. Run Development Server

```bash
pnpm run dev
```

## Security Notes

✅ **Safe to expose**:
- `publicAnonKey` from `utils/supabase/info.tsx` - Public anon key (protected by RLS policies)
- `projectId` from `utils/supabase/info.tsx` - Public project identifier

❌ **Never expose in frontend**:
- `RESEND_API_KEY` - Stored in Supabase secrets only
- Supabase service key - Used only in Edge Functions, never in frontend

## Common Issues

### Form submission fails with Supabase errors
- Verify tables exist in Supabase dashboard
- Check that RLS policies allow anonymous inserts
- Ensure `utils/supabase/info.tsx` exists (autogenerated by Make)

### Email not sending
- Check Edge Function logs: `supabase functions logs send-form-notification`
- Verify secrets are set: `supabase secrets list`
- Ensure FROM_EMAIL is verified in Resend (for production)

### Database insert fails
- Verify tables exist in Supabase
- Check RLS policies allow anonymous inserts
- View database logs in Supabase dashboard

### Success state shows but email not received
- Check Edge Function logs for errors
- Verify ADMIN_EMAIL is correct
- Check spam folder
- Verify Resend dashboard for delivery status
